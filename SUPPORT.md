# Support

Read [installation and development](README.md), [contributing](CONTRIBUTING.md), and the
[maintenance policy](docs/maintenance.md). This edition is independently maintained by LGTM Raycast.

Search [existing issues](https://github.com/lgtm-raycast/brew/issues) before opening a report. Include the downstream
commit/release, macOS/Raycast/Homebrew/Bun versions, exact reproduction, expected and actual behavior, and sanitized
logs. Use the bug or feature template. Security findings use [private reporting](SECURITY.md).

Upstream changes are reported in [the durable intake](https://github.com/lgtm-raycast/brew/issues/3). Discovery is
separate from adoption; feature/design decisions need the owner's input. Please report maintained-edition problems here
first and link relevant upstream issues. Support depends on maintainer availability.

Users control installation/update on each Mac. No maintenance workflow modifies an installed extension automatically.
